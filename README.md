# SynergyStacks — reference database upgrade

This package expands the ingredient, biomarker and mechanism reference layer.

## Included
- Duplicate ingredient and biomarker concepts removed by normalized label.
- Ingredient descriptions expanded into substantial educational reference text.
- Typical intake field added to ingredient records.
- Ingredient → mechanism → biomarker links rebuilt from more specific biochemical associations.
- Biomarker descriptions expanded.
- Mechanism descriptions expanded from the named pathway/process.
- Ingredient pages now show linked biomarkers and typical intake.
- Safety-warning panel and safety navigation removed from ingredient pages as requested.

## Install
Unzip this package over the project root, replacing the files inside `app/`. Then run the normal project checks/build.

The text is an editorial/educational layer intended for a later evidence pass. Primary citations have deliberately not been fabricated in this package.
